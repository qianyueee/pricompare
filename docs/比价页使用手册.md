# 比价页使用手册（简明版）

适用版本：v0.11.0 及以后。比价页参照汇总表里的 NEGO sheet：把几个零件的各家单价并排，按下单数量算「全给一家 vs 最优拆分」的总额。

## 1. 进入 / 退出

- 汇总页点 **A 列**选中要比的行 → 按 `Ctrl+B`（或点「比价」按钮），所选行自动带入；
- 不选行也能直接进，进去后自己输编号；
- 「← 返回汇总」或 `Esc` 回汇总页。**页内内容会保留**，下次进来接着用；想重来点「清空」。

## 2. 填编号

- 编号格直接打字；或在 Excel 里复制**一列编号**（或**编号 + 数量两列**）→ 点进编号格 `Ctrl+V`，自动一行行铺开；
- **同一个零件号只保留一行**（先出现的为准），重复的自动丢掉，手输重复会提示已合并到第几行；
- 编号在总表里找不到会标红「总表中未找到该编号」；
- 行尾 ✕ 删掉这一行；末尾永远留一空行可以继续加。

## 3. 填数量

- 编号填好后，数量格里灰字显示总表里这个件**有哪些数量档**，如 `1/3/6`；
- 输入数量后按 **`Tab`**：光标跳到下一行的数量格——下一件如果**有同样的数量档**就自动填上（文字是选中状态，要改直接打字），没有就留空等你手填；再按 `Tab` 用同一个数量继续往下（`Shift+Tab` 回上一行）；
- 数量不在档上时按阶梯取 **≤数量的最大档**单价，行内显示「取 X 档」；
- 这里改的数量**只用于比价，不会回写汇总表**。

## 4. 看结果

| 列 | 含义 |
| --- | --- |
| 各家单价(¥) | 出现过报价的供应商各一列，**绿色 = 本行最低** |
| 最低单价(¥) | 本行各家里最低的 |
| 各家总价(¥) | 该家单价 × 数量 |
| 最优总价(¥) | 本行最低单价 × 数量 |

底部合计行：各家总额（某家有没报的行会标「缺 N 行」，只合计已报的）与**最优拆分总额**（绿色）——两者的差就是谈判空间。

## 5. 把结果拿走

- **复制为表格**：放进剪贴板，回 Excel `Ctrl+V` 即可（NEGO 布局，含 Total 行）；
- **导出表格**：生成独立的 `NEGO_日期.xlsx`（全英文，最低价绿色高亮），可直接对外转发；
- **导出汇总表**时，比价页当前内容会**自动写进总表的 NEGO sheet**（按表头文字对齐各列，旧明细替换、表格下方备注不动；比价页空着则 NEGO sheet 原样不动）。

## 一分钟上手

1. Excel 里复制要比的一列零件号 → 比价页编号格 `Ctrl+V`；
2. 第一行数量格输入下单数量 → 一路按 `Tab`，同档的自动填、没档的手填；
3. 看绿色最低价和底部「最优」合计；
4. 「复制为表格」贴回 NEGO sheet，或直接「导出汇总表」一并写入。
