比价页使用手册（简明版）

参照汇总表里的 NEGO sheet：把几个零件的各家单价并排，按下单数量算「全给一家 vs 最优拆分」的总额。五步看完就能用。

进入→ 填编号→ 填数量→ 看结果→ 拿走结果

目录

  1. 1 进入 / 退出
  2. 2 填编号
  3. 3 填数量
  4. 4 看结果
  5. 5 把结果拿走
  6. 一分钟上手

1进入 / 退出

  • 汇总页点 A 列选中要比的行 → 按 Ctrl+B（或点「比价」按钮），所选行自动带入；
  • 不选行也能直接进，进去后自己输编号；
  • 「← 返回汇总」或 Esc 回汇总页。页内内容会保留，下次进来接着用；想重来点「清空」。

2填编号

  • 编号格直接打字；或在 Excel 里复制一列编号（或编号 + 数量两列）→ 点进编号格 Ctrl+V，自动一行行铺开；
  • 同一个零件号只保留一行（先出现的为准），重复的自动丢掉，手输重复会提示已合并到第几行；
  • 编号在总表里找不到会标红「总表中未找到该编号」；
  • 行尾 ✕ 删掉这一行；末尾永远留一空行可以继续加。

3填数量

  • 编号填好后，数量格里灰字显示总表里这个件有哪些数量档，如 1/3/6；
  • 输入数量后按 Tab：光标跳到下一行的数量格——下一件如果有同样的数量档就自动填上（文字是选中状态，要改直接打字），没有就留空等你手填；再按 Tab 用同一个数量继续往下（Shift+Tab 回上一行）；
  • 数量不在档上时按阶梯取 ≤数量的最大档单价，行内显示「取 X 档」；
  • 这里改的数量只用于比价，不会回写汇总表。

Tab 一路往下填数量，具体是怎么走的

举个例子，比价页里有 4 个件，总表里各自有的数量档是：

行零件总表里的数量档
1A1 / 3 / 6
2B3 / 6
3C10
4D3
  1. 点第 1 行数量格，输入 3，按 Tab → 光标跳到第 2 行；B 件有 3 这个档 → 自动填 3（数字是选中状态，不满意直接打字替换）；
  2. 再按 Tab → 第 3 行 C 件没有 3 档 → 留空，光标停在这里等你决定：要么手填（比如 10），要么什么都不填直接再按 Tab 跳过；
  3. 如果你跳过了第 3 行，再按 Tab 到第 4 行时，往下传的数量还是 3（沿用最近一次有值的格）→ D 件有 3 档 → 自动填 3；如果你在第 3 行手填了 10，往下传的就变成 10 → D 件没有 10 档 → 留空。

几条规则：

  • 每次按 Tab，往下传的数量 = 当前格的数量；当前格是空的（刚跳过没填）就沿用上一次的数量；
  • 下一行恰好有这个数量档才自动填，没有就留空——总表里的单价是按数量档报的，硬填一个没报过的数量会让单价按阶梯回落（显示「取 X 档」），容易看错；
  • 下一行已经有数量的不会被覆盖，只是光标跳过去（数字选中，想改就打字）；
  • 下一行还没填编号 → Tab 跳到它的编号格；
  • Shift+Tab 回上一行数量格，不改任何值。

4看结果

列含义
各家单价(¥)出现过报价的供应商各一列，绿色 = 本行最低
最低单价(¥)本行各家里最低的
各家总价(¥)该家单价 × 数量
最优总价(¥)本行最低单价 × 数量

底部合计行：各家总额（某家有没报的行会标「缺 N 行」，只合计已报的）与最优拆分总额（绿色）——两者的差就是谈判空间。

5把结果拿走

  • 复制为表格：放进剪贴板，回 Excel Ctrl+V 即可（NEGO 布局，含 Total 行）；
  • 导出表格：生成独立的 NEGO_日期.xlsx（全英文，最低价绿色高亮），可直接对外转发；
  • 导出汇总表时，比价页当前内容会自动写进总表的 NEGO sheet（按表头文字对齐各列，旧明细替换、表格下方备注不动；NEGO 是 Excel 表格时表格体整体替换、Total 行放表格下方；比价页空着则 NEGO sheet 原样不动）。

✓一分钟上手

  1. Excel 里复制要比的一列零件号 → 比价页编号格 Ctrl+V；
  2. 第一行数量格输入下单数量 → 一路按 Tab：下一件有同样数量档的自动填上，没有的留空等你手填（填完或直接再按 Tab 继续，往下传的是最近一次有值的数量）；
  3. 看绿色最低价和底部「最优」合计；
  4. 「复制为表格」贴回 NEGO sheet，或直接「导出汇总表」一并写入。
