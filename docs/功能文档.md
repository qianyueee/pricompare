# 询价比价系统 功能文档

版本：v0.4.0 ｜ 适用平台：Windows 10/11（64 位）

---

## 1. 系统定位

本系统是一个**本地桌面应用**，围绕你们的 **「KK 询价汇总表」** 工作：

- 打开程序就是完整的历史汇总大表（上次载入的汇总持久保存在本机）；
- 邮件里收到的供应商报价 Excel（HC、KV/SKW 等各家格式不同）直接**拖进窗口**，按既有规则**自动并入**汇总；
- 随时点格子**直接编辑**；选几行按 `Ctrl+B` 进入 **NEGO 比价**；
- 一键**按原格式导出**——以你上传的原工作簿为底，只更新数据区，NEGO 等其他 sheet、公式、批注、样式全部原样保留。

**所有数据只在本机处理与存储，不联网、不上传。**

核心概念只有三个：

| 概念 | 含义 |
| --- | --- |
| 工作底表 | 程序内持久保存的汇总表（最后一次载入的汇总 + 之后的并入与编辑） |
| 批次 | B 列（Name）里的询价批次名，如 `20260814 Natalie A`；并入报价时自动写入 |
| 供应商槽位 | 汇总表 I–N 六列（Mao / HC / SKW / BY / YJ / JM），每家占一列 |

## 2. 安装与更新

1. 打开仓库 **Actions** 页 → 最新一次绿色 ✓ 的「打包 Windows 安装包」运行 → 页面底部 **Artifacts** 下载 `询价比价系统-Setup-win-x64`（zip 内即 `询价比价系统-Setup-0.4.0.exe`）。
2. 安装包未做代码签名，首次运行 Windows SmartScreen 会提示「未知发布者」→ 点「更多信息 → 仍要运行」。
3. 安装时可自选目录；**卸载不会删除数据**（汇总底表、映射模板都保留）。
4. 更新：直接安装新版覆盖即可，本机数据不受影响。

数据存放位置：`%APPDATA%\询价比价系统\store\`（JSON 文件）。换电脑时最简单的迁移方式是「导出汇总表 → 新机器上重新载入」。

## 3. 主界面

打开程序即汇总大表。工具条从左到右：

| 控件 | 作用 |
| --- | --- |
| ＋ 导入（报价 / 汇总表） | 选文件导入；与整窗拖放等效 |
| 导出汇总表 | 按原格式导出（右侧琥珀色小圆点 = 有未导出的更改） |
| 比价 Ctrl+B | 打开 NEGO 比价面板（详见第 8 节） |
| 已选 N 行 | 当前用 A 列选中的行数 |
| 文件信息 | 底表来源文件名 · 数据行数 · 批次数 |
| 全部批次（下拉） | 只看某一个批次 |
| 搜索框 | 按 P/N / 描述 / 批次 / 报价单号 过滤 |
| 显示空行 | 显示/隐藏底部只有 A 列序号的预编号空行 |

表格本身：

- 33 列与 Excel 汇总表一一对应，表头带 Excel 列字母（A–AG），**A–D 列冻结**不随横向滚动；
- **显示时最新批次在最上**（同批次内部保持原顺序）——只是显示顺序，**导出仍按原表顺序**；
- 供应商列（I–N）**绿色 = 本行最低价**（`￥1,133.40` 这类文本价也参与比较；≥2 家有价才标）；`TDB` / `待定` 显示琥珀色；
- 把文件拖到窗口任意位置即可导入（汇总表和报价文件都可以，程序自动识别是哪种）。

## 4. 载入 / 更新汇总表

把 `KK询价汇总表xxxx.xlsm`（或 .xlsx）拖进窗口：

1. 程序自动识别出这是汇总表（找名字含「汇总」或表头匹配的 sheet）；
2. 弹窗显示数据行数，并提示「将自动规范 N 个文本格式金额」（见第 7 节）；
3. 确认后成为新的工作底表，**整表替换**旧底表，并持久保存——下次打开程序即见；
4. 原文件同时在本机留存，作为之后「按原格式导出」的底版。

> 提示：随时可以把最新的汇总表拖进来整表刷新，比如同事在 Excel 里改过之后。

## 5. 并入供应商报价

把 HC / KV(SKW) 等报价文件拖进窗口，弹出**映射确认**：

- **供应商**：按文件名、表头、单号特征自动猜（HC、SKW 一般都能猜中）；不认识的家可手工填名字并选一个 I–N 槽位；
- **批次（同一批自动识别）**：优先从「询价 20260814 Natalie A」这类单号/文件名取；回单里**没有**批次信息时（如 KV 只有自家单号 `KV202608151`），按**零件号 + 数量集合**自动匹配——与总表里已并入的批次吻合、或与同时拖入的另一家报价零件相同，就自动填成同一批并在输入框下方注明识别依据（始终可手改）；
- **价格列**：默认选 Quote (each) 一族的列；表头下方每列都可改映射；
- **并入预览**：确认前直接显示「并入预览：更新 X 行 · 新增 Y 行」。

同一格式的文件**确认一次后记住映射**，下次拖入自动填好，直接点确认即可。

### 并入规则（从真实汇总 0812 → 0814 快照逐单元格 diff 实证）

| 项目 | 规则 |
| --- | --- |
| 行匹配 | 每条报价（P/N × 数量档）**自底向上**找「同 P/N + 同数量 + 该家槽位还空着」的行 → 填入该行 |
| 新增行 | 找不到可填行 → 优先占用底部**预编号空行**（只有 A 列序号的行，A 序号保留），用完后续号追加 |
| 价格槽位 | HC 填 J 列、SKW 填 K 列，其余家按注册表槽位 |
| W 交期 | 按槽位列序拼接：J 在前、K 在后 → `18Days/3 weeks+cleaning`；纯数字自动补 Days（22 → `22Days`） |
| V 报价单号 | 只收**真单号**（如 `KV202608151`、`KT20260711B`）；「询价 20260814 Natalie A」这类识别为**批次名**写入 B 列，不进 V |
| H 选定价 / U 对客报价 | 只从带 **Quote (EA)** 列的报价文件带入（KV 家宏算好的），且只填空不覆盖 |
| 规格列（材料/表面处理/清洗/工艺/尺寸） | 空则填；SKW 的中文规格值优先覆盖 |
| 备注 | 与已有备注冲突时，带供应商前缀追加，不丢原文 |
| B 批次 | 本次并入的所有行统一写批次名 |

报价文件里的各种脏东西都能处理：表头不在第 1 行（HC 在第 3 行）、中英双语列名、`#REF!` 错误格、宏说明垃圾行、` 2` / `Column1` 垃圾列、阶梯报价（同 P/N 多个数量档各占一行）。

## 6. 直接编辑与选区操作

### 单格编辑

- **单击任意单元格**进入编辑，`Enter` 保存、`Esc` 取消；
- 金额列输入 `￥1,360.00` 这类文本会自动规范成数字 `1360`；
- 每次编辑**立即保存**在本机；工具条出现「（有未导出更改）」与琥珀色圆点提醒尚未导出。

### 选区（类 Excel，v0.7.0 新增）

- **选行**：点 **A 列**格子逐行选/取消；**按住 A 列拖动**选连续多行；点表头 A 格一键清空；
- **选列**：点**表头**选整列；**按住表头拖动**选连续多列；
- **选格区**：在数据格上**按住拖动**框选矩形多格（单击不拖动仍是进入编辑）；
- 三种选区互斥，选中后底部浮出操作条（复制 / 清空内容 / 删除行 / 取消）。

### 选区操作

| 操作 | 方式 | 说明 |
| --- | --- | --- |
| 复制 | `Ctrl+C` 或「复制」 | 按显示顺序复制为表格（行=整行 33 列；列=可见行×所选列；格区=矩形），可直接粘贴进 Excel |
| 清空内容 | `Delete` 或「清空内容」 | 所选内容置空；**A 列序号保留**；列/格区只影响当前可见行（尊重批次筛选/搜索） |
| 删除行 | 「删除行」按钮 | 整行移除、后续行上移，**A 列序号自动重排**；导出仍按原格式字节级补丁 |
| 撤销 | `Ctrl+Z` 或「撤销」 | 单格编辑、清空、删除行均可撤销**最近一步** |

## 7. 文本金额自动规范

汇总表和报价表里历史遗留的「字符串格式金额」（Excel 左上角绿色小三角那种），在**载入汇总、并入报价、手工编辑**时自动转成真正的数字：

- 处理范围：**G 数量列 + H–U 金额列**；
- 能处理：`￥1,133.40`、`$935.00 `（尾带不换行空格）、全角逗号、`'315'` 纯数字文本等；
- **不会动**：`没有图纸`、`做不了`、`TDB`、`待定` 这类备注文字，原样保留；
- 载入汇总时弹窗会提示共规范了多少个（实测真实 0814 汇总表一次规范 357 个）。

## 8. NEGO 比价页（v0.6.0 起为独立页面）

参照汇总表里 NEGO sheet 的谈判逻辑：把零件的各家单价并排，按**下单数量**算「全给 HC / 全给 SKW / 最优拆分」三种总额，谈判前一目了然。

### 进入与返回

- **选行进入**：点汇总表 **A 列**（序号格）选中若干行（✓ 蓝色高亮，再点取消；点**表头 A 格**一键清空），工具条显示「已选 N 行」→ 按 `Ctrl+B`（Mac 为 `Cmd+B`）或点「比价」按钮，所选行自动带入；
- **直接进入**：不选行也可以进，页内直接输入编号；
- 「← 返回汇总」或 `Esc` 回汇总大表；**比价页内容保留**，下次进入接着用，「清空」按钮重来。

### 类 Excel 的编号 / 数量输入

- 表格前两列（**编号、数量**）像 Excel 一样点格直接输入；`Enter` 跳到下一格；行尾 ✕ 删行；末尾恒有一空行可继续加；
- **整列粘贴**：在 Excel 里复制一列编号（或**编号+数量两列**）→ 点进比价页某格 `Ctrl+V`，自动逐行铺开；
- **数量档提示**：编号填入后、数量还没填时，数量格里**灰字显示总表中该件的有效数量档**，如 `1/3/6/9/12`（同一数量多次询价取最近一次）；
- 数量不在档上时按**阶梯语义**取 ≤数量 的最大档单价（行内亮「取 X 档」徽标注明），总价仍按输入数量算；
- 查不到的编号红色提示「总表中未找到该编号」。

### 比价与合计

| 列 | 说明 |
| --- | --- |
| 编号 / 数量 | 可编辑（上述） |
| Rev / 描述 | 按总表解析自动带出 |
| 各家单价 | 出现过报价的供应商各一列；**绿色 = 本行最低** |
| 最低单价 | 本行各家最低 |
| 各家总价 | 单价 × 下单数量 |
| 最优总价 | 本行最低单价 × 数量 |

底部合计行：各家总额（某家有缺报会标「缺 N 行」，其合计只含已报行）与**最优拆分总额**（绿色）。

> 示例：某件五档阶梯询价——HC 全单 57,128 / SKW 全单 52,900 / 最优拆分 52,420（其中一档 HC 更低、其余档 SKW 低，拆开下单比全给任何一家都省）。

### 复制为表格

「复制为表格」把当前比价结果按 NEGO sheet 布局（含合计行）放进剪贴板，回 Excel 直接 `Ctrl+V` 粘贴即可。

## 9. 导出汇总表

点「导出汇总表」：

- **以你上传的原工作簿为底做字节级补丁**：只改动数据区变过的单元格，其余部分（NEGO 等 sheet、A 列公式、批注、样式、列宽、customXml）逐字节保留——导出文件可直接替换你现有的汇总文件；
- **扩展名跟随原文件内容**：原表是 .xlsm（含宏内容类型）就导出 .xlsm，否则 .xlsx，Excel 不会再报「格式或扩展名无效」；
- 默认文件名 `KK询价汇总表YYYYMMDD.xlsm`；
- 没有原底版时（从零新建的汇总）按 KK 模板重建导出。

导出后「未导出更改」标记清除。

## 10. 数据与安全

- 汇总底表、映射模板、供应商别名保存在 `%APPDATA%\询价比价系统\store\*.json`；上传的汇总原文件同样本地留存作导出底版；
- 程序不联网、不上传任何数据；
- Excel 解析使用开源库 `xlsx@0.18.5`，该版本对**恶意构造的文件**存在已知 CVE——本程序只用来解析你自己邮箱收到的报价，风险可控，请勿当公开上传服务用。

## 13. 常见问题

**导出的文件 Excel 打不开 / 提示扩展名无效？**
v0.2.2 起导出扩展名自动跟随内容（.xlsm 原表导出 .xlsm），请勿手工改后缀。若使用旧版导出的文件报错，把后缀改回 .xlsm 即可打开。

**程序里的行顺序和 Excel 里不一样？**
显示层最新批次排最上，方便看新询价；数据与导出始终保持原表顺序。

**供应商识别错了？**
在映射弹窗里直接改供应商名并选槽位；同格式确认一次后会记住。

**比价面板里改数量，会改动汇总表吗？**
不会。面板里的数量只用于当次比价计算；汇总表数据不变。

**数量档里出现 `?`？**
该行 G 列（数量）为空或不是数字，规范数据后即正常。

**误删了行 / 误清空了内容？**
`Ctrl+Z` 撤销最近一步（单格编辑、清空、删除行都支持）。只保留一步——更早的状态用上一次导出的汇总表重新拖入恢复。

**误并入了一份报价怎么办？**
并入没有撤销：把上一次导出的汇总表重新拖入，整表刷新即可回到并入前状态（建议重要操作前先导出一份留底）。

**换电脑怎么迁移？**
新机器装好程序后，把最新导出的汇总表拖入载入即可；映射模板会在下次拖入同格式报价时重新确认一次。
